  - **8.2.0 changes**: Non-Node runtime framework mode no longer requires custom `entry.server.tsx` -- Web Streams API becomes the default entry. Node apps can opt in via `future.unstable_enableNodeReadableStream`. `nub` package manager detection added.

- **Migration recommendation**: Stay on Remix v2. Plan RRv8 as migration target. `@nx/remix` should surface RRv8 as the recommended path. Trigger: ESM interop resolved in `@nx/react-router` + RRv8 framework mode validated.

### Nuxt

- **Current stable**: 4.5.1 (was 4.4.8 -- new minor!). Nuxt 3.x: 3.21.10 (entering EOL July 31, 2026).
- **Key changes (4.5.0)**:
  - **Vite 8 migration** -- Nuxt now requires Vite 8 (breaking dep bump). Custom plugins must be audited per Vite 8 migration guide.
  - **Rspack 2 + Rsbuild** -- Rspack builder upgraded to Rspack 2, rebuilt on Rsbuild. Same public API, better dev server performance via middleware mode.
  - **SSR Streaming (experimental)** -- HTML shell flushed immediately; body streamed as Vue renders. Improves TTFB for content-heavy routes.
  - **Stable error codes** -- `NUXT_E1001` etc., with dedicated docs pages.
  - **New composables**: `useLayout` (resolved layout of current route), `enabled` option for `useFetch`/`useAsyncData` (reactive gate).
  - **Named views** via filename convention (`name@view.vue`).
  - **NuxtLink**: custom slot rendering exposes prefetch controls.
  - **Breaking**: `unhead` v3 stricter type-narrowing for `useHead`; Promise input deprecated in `useHead`.
  - **Nuxt 3 EOL: July 31, 2026.**
- **@nx/nuxt impact**: P0 escalation. The Vite 8 dep bump means `@nx/nuxt` generators and executors must be verified against Vite 8. The Rspack builder change (now using Rsbuild) may affect how `@nx/nuxt` wraps the Rspack path. Nuxt 3 EOL should prompt a deprecation notice in Nx docs.
- **Action needed**: Immediate compat pass for Vite 8 + Rsbuild; update peer deps; add Nuxt 3 EOL notice to docs.

### Rolldown

- **Current**: 1.2.0 (was 1.1.4 -- new minor!).
- **1.2.0 changes**:
  - **HMR improvements**: client-side HMR, per-client ship map for HMR patch sizing (more efficient HMR for large projects).
  - **`import.meta` handling**: `import.meta['url']` and `import.meta['ROLLUP_FILE_URL_*']` treated as side-effect free.
  - **tsconfig-change full-reload**: sends full-reload update to clients when tsconfig changes.
  - **ESM format naming change**: uses `es` instead of `esm` in `*FileNames` options (potential break in custom output config).
  - Bug fixes: sourcemap composition, tree-shaking of destructured dynamic imports, glob path resolution with tsconfig paths.
- **@nx/vite impact**: P2. Rolldown 1.2 is Vite's internal bundler. The `esm`->`es` naming change could affect custom Vite configs that reference Rolldown output filenames directly. Validate Vite 8.1.5 + Rolldown 1.2 integration in Nx test matrix.
- **Nx relevance**: No standalone plugin needed. Rolldown is Vite-internal.

### esbuild

- **Current**: 0.28.1 (no change from July 6).
- **Key changes**: None.
- **@nx/esbuild impact**: P2 carryover -- 0.28 peer bump + Go 1.26 GC validation still pending.

### webpack

- **Releases**: 5.109.0 (was 5.108.4 -- new minor, July 2026).
- **Key changes (5.109.0)** -- SIGNIFICANT:
  - **`experiments.typescript: "auto"`** -- Built-in TypeScript support activates on Node 22.6+ when no TS loader is registered. Nx-scaffolded configs use `ts-loader`/`babel-loader`, so activation should NOT occur -- but interaction must be verified.
  - **`experiments.css/html/wasm: "auto"`** -- Same auto-detection pattern for CSS, HTML modules, WASM.
  - **`import.meta.glob`** -- webpack now natively supports Vite-style glob imports.
  - **`import.meta.resolve()`** -- resolves asset URLs at compile time.
  - **`import.meta.env`** -- `MODE`, `DEV`, `PROD`, `SSR`, `BASE_URL` now native (matches Vite's env API).
  - **`output.resourceHints`** -- emits preload/prefetch/modulepreload/preconnect hints for ESM output.
  - **CommonJS module concatenation** -- CJS modules with statically analyzable exports can be concatenated.
  - **Enhanced HTML output** -- title, meta, base, favicon, web app manifest, inline CSP hashes.
  - **`importMetaContext` deprecated** -- replace with `importMeta.webpackContext` in generated configs.
  - Performance improvements: faster JS/CSS/HTML parsing, reduced memory allocation.
- **@nx/webpack impact**: P1. `importMetaContext` deprecation is a direct code change in any generated config or executor that references it. The TypeScript auto-mode needs a verify pass to confirm it doesn't conflict with Nx's loader setup. The `import.meta.glob/env/resolve` additions are Vite-parity features worth documenting so users know they work in webpack too.
- **Competitive signal**: webpack is aggressively closing feature gaps with Vite (glob, env vars, resource hints). This weakens the "switch to Vite for modern APIs" argument and may reduce churn away from `@nx/webpack`.

## Cross-Cutting Themes

### 1. Nuxt 3 EOL and Nuxt 4.5: Vite 8 mandatory
Nuxt 3 reaches end-of-life July 31, 2026. Nuxt 4.5 requires Vite 8. This double event means `@nx/nuxt` needs immediate work: verify Vite 8 compat, update peer deps, add EOL messaging for Nuxt 3 users, and validate the Rspack+Rsbuild builder path. Highest-urgency new item this run.

### 2. Vue 3.6 RC: Vapor Mode changes the @nx/vue generator story
Vue 3.6 exiting beta and entering RC (July 18) is a milestone. Vapor Mode is opt-in, not forced -- but generator scaffolding should expose it. The reactivity refactor (alien-signals) has no consumer-visible API change but may need snapshot validation. Vue 3.6 stable is likely August-September.

### 3. webpack 5.109: Vite-parity features land natively
`import.meta.glob`, `import.meta.env`, resource hints, and auto-mode for TS/CSS are now native in webpack. This is the largest single-release feature addition to webpack in years and positions it competitively against Vite for new projects. Nx's webpack plugin benefits automatically but needs docs and a verify pass.

### 4. Three concurrent P0/P1 actions: Nuxt 4.5 compat, `@nx/rspack` v2, `@nx/vite` hmr rename
The trio from the July 6 report has grown. Nuxt 4.5 Vite 8 requirement is a new P0, joining the long-standing `@nx/rspack` v2 gap and `server.hmr` -> `server.ws` rename in `@nx/vite`.

### 5. Angular 22.1 and Vue 3.6 both entering stable window August 2026
Two major framework minor/major releases are likely in August. Nx should be prepared for `@nx/angular` 22.1 and `@nx/vue` 3.6 compat simultaneously.
