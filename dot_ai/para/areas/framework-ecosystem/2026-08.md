## Frameworks

- **Releases this period**: 22.1.0 (July 29, now stable). Next: 22.2.0-next.0.
- **Key changes (22.1.0)**:
  - **JSONP deprecated**: `HttpClient.jsonp`, `HttpClientJsonpModule`, all related JSONP classes/functions. Migrate to standard HTTP requests.
  - Signal forms expanded: utility to assert field tree values.

- **Action needed**: JSONP sweep in generated code; unlock 22.1 follow-on work.

## Cross-Cutting Themes

### 1. Nuxt 4.5.1 security -- highest urgency item this month
Multiple critical CVEs in Nuxt 4.5.0 make 4.5.1 a mandatory security upgrade. The `@nx/nuxt` peer dep must pin to `>=4.5.1`. Separately, the Vite 8 + Rsbuild internal migration in 4.5.0 represents a large compatibility surface that needs validation. These two items together make Nuxt the highest-priority action for August.

### 2. Next.js `experimental.useCache` deprecated -- signal for 16.3 GA proximity
The deprecation of `useCache` in canary.106 plus preview.10 reaching maturity suggests 16.3 stable is approaching. 28 canaries in 28 days is the same aggressive pace as July. No date announced but pattern suggests Q3 2026 is still the target. Pre-GA validation should begin now.

### 3. React Router v8.3.0 accelerating RSC surface
Two minor versions (8.2 and 8.3) in one month with RSC virtual modules, web streams defaults, and TypeScript 7 support. The Nx plugin needs to keep pace. ESM interop (P0 carryover) remains the blocking issue.

### 4. Vue 3.6 enters RC -- VDOM users unaffected, Vapor API stabilizing
The RC stage means a stable 3.6 release in the near term. VDOM code is unaffected. Vapor Mode has its first API breaking change (event delegation opt-in) confirming the API is still being shaped. Plan `@nx/vue` 3.6 compat now rather than at GA.

### 5. webpack 5.109 soft-breaking change: experiments auto
The `experiments: "auto"` default is a soft breaking change that will silently activate handlers in existing projects. This is the kind of change that surfaces as hard-to-diagnose build conflicts. Proactive audit of Nx-scaffolded configs is warranted before users hit it.

### 6. Remix v3 stalled -- pause feasibility spike
Five weeks of silence after beta.5 suggest refinement or slowdown. The July recommendation to spike at beta.8 stands -- there's no trigger yet.
